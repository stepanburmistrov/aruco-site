Генератор ChArUco Board

Настройте количество клеток, размер клетки и словарь. Размер маркера внутри клетки рассчитывается автоматически. Получите масштабируемый SVG и готовый код OpenCV для такой же доски.

Маркер занимает фиксированные 70% стороны клетки и отдельно не настраивается.

Тот же Board в Python

Если нужна высокая точность углов для калибровки, ChArUco обычно удобнее одиночных ArUco: шахматные углы можно уточнять точнее, а маркеры помогают идентифицировать видимую часть доски.

Печатайте только в масштабе 100%. Генератор показывает физический размер доски и предупреждает, если она не помещается на A4. Уменьшение «под размер страницы» делает указанные размеры неверными.

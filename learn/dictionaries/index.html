Словари ArUco: 4×4, 5×5, 6×6 и 7×7

Название словаря уже содержит две важные характеристики. Разберём их без лишней теории.

Как читать название словаря

Название DICT_4X4_250 читается просто: внутренняя полезная матрица имеет размер 4×4, а словарь содержит 250 допустимых маркеров. У вариантов 5×5, 6×6 и 7×7 внутри больше битов.

Что выбрать для первого проекта

Для учебных задач удобно начать с DICT_4X4_250: маркер хорошо виден крупными клетками, а 250 ID обычно более чем достаточно. Если проекту нужен больший кодовый запас или другие требования к устойчивости, можно перейти к матрице большего размера.

DICT_7X7_2507×70–249Когда размер клетки остаётся достаточным для камеры

Главная ошибка

Нельзя генерировать маркер в одном словаре, а искать его другим. Изображение может выглядеть корректным, но ID не совпадёт с набором допустимых кодов выбранного детектором словаря.

Проверить на практике

Создайте один и тот же ID в разных словарях: визуально это будут совершенно разные бинарные коды. Затем переключайте словарь в браузерном сканере.

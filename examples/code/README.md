# ArUco + OpenCV: готовые примеры

Все размеры в 3D-примерах задаются в метрах. Под размером маркера понимается
внешняя сторона чёрного квадрата; белое поле вокруг него не учитывается.

## Установка

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
```

Не устанавливайте одновременно `opencv-python` и `opencv-contrib-python` в одно
окружение: модуль `cv2.aruco` входит в contrib-сборку.

## Порядок работы

1. `01_generate_marker.py` — генерация одного маркера.
2. `02_detect_image.py` — поиск маркеров на фотографии.
3. `03_detect_camera.py` — поиск с камеры.
4. `05_generate_charuco.py` — генерация доски с теми же параметрами, что на сайте.
5. `07_capture_calibration_images.py` — съёмка разнообразных кадров ChArUco.
6. `06_charuco_calibration.py` — расчёт матрицы камеры и дисторсии.
7. `08_validate_calibration.py` — визуальная проверка калибровки.
8. `04_pose_estimation.py` или `09_marker_pose_live.py` — положение относительно камеры.
9. `10_calibrate_camera_mount.py` — привязка неподвижной камеры к столу.
10. `11_marker_pose_world.py` — положение относительно стола/стенда.

Дополнительно:

- `12_marker_id_actions.py` показывает события по ID без многократного срабатывания;
- `13_ros2_marker_pose_publisher.py` публикует `PoseStamped` в ROS 2;
- `aruco_pose_utils.py` содержит общие функции 3D-геометрии.

## Системы координат

В `tvec` OpenCV используется оптическая система камеры: X вправо, Y вниз,
Z вперёд от камеры. `10_calibrate_camera_mount.py` создаёт систему мира по
опорному маркеру: X вдоль его верхнего края вправо, Y к верхнему краю, Z из
плоскости маркера. Для лежащего на столе маркера Z направлена вверх, если
печатная сторона обращена к камере.

Преобразования записаны как однородные матрицы 4×4. Координата маркера в мире:

```text
T_world_marker = T_world_camera @ T_camera_marker
```

## Что измерить физически

- клетку ChArUco и чёрный квадрат маркера после печати;
- размер рабочего ArUco по внешней стороне чёрного квадрата;
- разрешение камеры: после калибровки не менять его;
- положение опорного маркера: он задаёт начало и оси системы мира.

Для качественной калибровки снимите 15–30 резких кадров, заполняя доской центр,
углы и края изображения, меняя наклон и расстояние. Серия почти одинаковых
кадров точность не улучшает.

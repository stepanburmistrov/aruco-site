Генератор ArUco-маркеров для печати

Соберите лист с маркерами OpenCV: задайте внешний размер карточки или размер чёрного квадрата — второе значение пересчитается автоматически по модульной сетке выбранного словаря.

Карточка целиком вместе с белым полем.
Размер для pose estimation; связан с внешним размером.
Размеры связаны: можно изменить любой из них. Белое поле вокруг ArUco равно ширине одного модуля маркера.
Белое поле с каждой стороны: 7.5 мм.

Как печатать правильно

Печатайте с масштабом 100% и отключайте «подогнать под страницу». Физический размер маркера особенно важен, если дальше вы рассчитываете положение относительно камеры.

Внешний и чёрный размеры связаны.
Чёрный квадрат включает код и чёрную рамку, а внешний размер дополнительно включает по одному белому модулю с каждой стороны. Для solvePnP используйте указанную длину чёрного квадрата.

# Яндекс Метрика — счётчик 111624278

В код сайта уже встроен счётчик 111624278.

Рекомендуемые цели типа «JavaScript-событие»:

- `home_generator` — переход с главной в генератор
- `home_detector` — переход с главной в сканер
- `generator_use` — сборка/изменение листа маркеров
- `generator_svg` — скачивание SVG
- `generator_png` — скачивание PNG
- `generator_print` — печать / сохранение PDF
- `detector_camera_start` — запуск камеры
- `detector_camera_switch` — переключение камеры
- `detector_image_load` — загрузка изображения в сканер
- `marker_detected` — браузерный сканер уверенно определил ID
- `charuco_generate` — изменение параметров ChArUco
- `charuco_svg` — скачивание ChArUco SVG
- `charuco_print` — печать ChArUco
- `python_example_download` — скачивание Python-примера
- `to_robotx` — переход на robotx.su
- `to_rosikbot` — переход на rosikbot.ru
- `to_channel` — переход в канал автора

Для `reachGoal` часть событий дополнительно передаёт параметры: словарь, ID, размеры, страницу и т. п.
